# Future examples

Examples are intentionally not included in the initial public source tree.

- grasshopper/: placeholder for future reviewed Grasshopper definitions.
- plaxis/: placeholder for future reviewed PLAXIS examples, if redistribution is intended.

Git does not preserve empty directories, so .gitkeep files retain these locations.
GH and PLAXIS model formats are ignored by default to prevent accidental publication.
Only explicitly reviewed, credential-free examples should be added later. The maintainer
can narrow the ignore rules when a specific example is ready.
