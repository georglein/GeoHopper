GeoHopper - Project overview

Vision: a general Grasshopper plugin for parametric geotechnical modelling and PLAXIS
analysis. Grasshopper defines the model; PLAXIS solves it; results return to Grasshopper.
Long-term work includes optimization of deformation and material use.

Implementation: direct C# encrypted local API; no Python backend or exchange-file workflow.
Build, Calculate and Read Results are explicit actions. All documentation and UI are
English. Physical values use SI units. Stable component IDs preserve GH compatibility.

Current development version: 0.6.0.0, with 18 components and embedded icons.
Excavation WP1 was accepted by the maintainer. WP2 adds plate contacts, refinement and K0; see docs/WORK-PACKAGES.md for status and next steps.
Existing wall build/calculation and C# Output access have been exercised previously;
the new excavation/contact/K0 workflow requires live acceptance.

Components and their purposes are listed in README.md and detailed in docs/COMPONENTS.md.
Examples are intentionally withheld; examples/ contains placeholders only.

Development: this repository root is the working project. Build/test into artifacts;
publish to dist only while Rhino is closed. Load one GeoHopper copy in Grasshopper.
Keep private GH/PLAXIS projects and credentials outside the repository.

Next: jointly test Excavation WP2, then develop struts (WP3) and structural results (WP4). Source publication does not imply that
engineering assumptions or analysis results have been independently validated.
